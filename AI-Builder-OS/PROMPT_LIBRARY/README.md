# Prompt Library

## Purpose

This library contains reusable prompt templates used within the AI Builder Operating System.

The goal is to:

- Reduce prompt writing effort
- Improve consistency
- Reduce AI token usage
- Standardize engineering workflows
- Improve implementation quality

These prompts are templates.

Replace only the project-specific details before sending them to Claude.

---

## General Principles

Each prompt should:

- Have a clear objective
- Define scope
- Specify constraints
- Include acceptance criteria
- Avoid unnecessary background information

---

## Preferred Workflow

ChatGPT:

- Feature planning
- Architecture
- Prompt generation
- Code review

Claude:

- Implementation
- Refactoring
- Testing
- Documentation updates

---

## Prompt Categories

| Prompt | Purpose |
|---------|---------|
| Feature Implementation | Implement a planned feature |
| Code Review | Review generated code |
| Bug Fix | Fix a specific defect |
| Refactoring | Improve existing code |
| Documentation Audit | Synchronize documentation |
| Architecture Review | Review system design |
| Release Preparation | Final verification before release |
| Testing | Generate or improve tests |
| UI Implementation | Build frontend features |
| Backend API | Build backend endpoints |
