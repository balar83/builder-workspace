# Wireframes
**Project:** Math Thinking Coach  
**Version:** 1.0

---

# Design Principles

- Mobile First
- Minimal UI
- One primary action per screen
- Reduce cognitive load
- Encourage thinking instead of answering
- Child-friendly interface

---

# Screen 4 - Thinking Mode

```
----------------------------------------

Question

----------------------------------------

Hint 1

What operation removes +5 ?

----------------------------------------

[ Next Hint ]

[ Explain Again ]

[ Show Solution ]

----------------------------------------
```

Purpose

Guide thinking without revealing the answer.
