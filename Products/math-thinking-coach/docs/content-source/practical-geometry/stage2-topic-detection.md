# Stage 2 — Topic Detection: Practical Geometry (expansion)

**Input:** `practical.pdf` (user-supplied, 2026-08-15), NCERT Class 8 Mathematics Exemplar Problems, Unit 5, "Understanding Quadrilaterals and Practical Geometry" — the two source chapters are bundled together in this Exemplar unit. Content was split by topic: general polygon/quadrilateral-property material (definitions, angle-sum reasoning, parallelogram/rhombus/rectangle property questions) belongs to **Understanding Quadrilaterals**, which already has its own Topic and 40-question bank from Release 0.1.1 — that material is not duplicated here. The **construction-specific** material — the four measurement-combinations that determine a quadrilateral uniquely (4 sides + 1 diagonal; 3 sides + 2 diagonals; 2 adjacent sides + 3 angles; 3 sides + 2 included angles), worked construction examples (Examples 26, 34–38), and construction-sufficiency exercises (Exercises 186–203, 196–197) — is what this expansion draws on for Practical Geometry.

**Architectural blocker (reported before proceeding, per the milestone brief's own instruction to stop rather than silently expand scope):** Practical Geometry has no Topic in the runtime data (`topics.json`) and, per this milestone's explicit scope, is not getting one — expanding the question bank only, no Learn page. However, the Stage 10 export pipeline's referential validation (`referentialValidation.js`) requires every question's `topicId` to resolve to either a Topic being exported in the same run or an existing Topic already in `topics.json`. There is no code path for "export questions for a chapter with no Topic at all." This is exactly how the existing 5 placeholder Practical Geometry questions came to exist outside the pipeline in the first place (confirmed: no `docs/content-source/practical-geometry/` directory existed before this expansion).

**Resolution (approved by Product Architect, 2026-08-15):** this expansion's questions are written to the same canonical shape as every other chapter (`stage6-questions.json`, `answer-keys.json` below) for documentation and audit consistency, but are merged into the runtime `questions.json`/`answer_keys.json` by a direct, hand-run script rather than `docs/content-pipeline/export/run.js` — because the pipeline genuinely cannot do this for a topic-less chapter. Every question is still validated against the real backend Pydantic `Question` schema (via `validate_runtime.py`, the same validator the pipeline itself shells out to) before being written, so this is not unvalidated content — it just isn't pipeline-*orchestrated*. No `canonical-topic.json` exists for this chapter, by design.

## Question-shaped material used

Instrument identification (compass, ruler, protractor); the "five measurements determine a quadrilateral uniquely" principle and its four valid combinations; how many measurements are sufficient/necessary for special quadrilaterals (square, rectangle, rhombus, parallelogram); angle-sum and Pythagorean-relation computations that arise directly from a construction's given measurements (e.g. finding a rectangle's diagonal from its sides, or a rhombus's side from its diagonals); true/false questions on construction sufficiency. Full list authored at Stage 6.

**Note on originality**: all questions are written in this project's own voice — not reproduced verbatim from the NCERT Exemplar's MCQ/fill-blank wording.
