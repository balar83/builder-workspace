# Stage 4 — Learning Objectives: Data Handling

Derived from Stage 3 concepts (Option A structure — see Stage 2 flag). Grouped by section for traceability.

## Section 1 — Reading graphs you already know
1. Read and interpret values from a pictograph, bar graph, or double bar graph.
2. Explain why rearranging a bar graph's bars does not change the information it conveys.

## Section 2 — Pie charts: showing parts of a whole
3. Explain what a pie chart's sector size represents in relation to the whole.
4. Calculate a sector's central angle from its fraction of the total, using (part/whole) × 360°.
5. Construct a pie chart from a data table using a protractor.
6. Given one sector's real-world value and percentage, find the real-world value of another sector via the unit rate.

## Section 3 — Chance and probability
7. Distinguish a random experiment from one with a predictable outcome.
8. Identify the outcomes of a simple random experiment (coin toss, die throw, spinner).
9. Identify whether a set of outcomes is equally likely.
10. Calculate the probability of an event as (favourable outcomes) / (total equally likely outcomes).
11. Name a real-life context where probability estimates are used (e.g. exit polls, weather prediction).

**Curriculum-alignment note:** objectives 3–6 map to Exercise 4.1 (`dh-raw-05`); objectives 7–10 map to Exercise 4.2 (`dh-raw-08`). Objective 11 is knowledge-level (naming an application), not exercised by any question in the source — flag for Stage 6 if you want a question written to cover it, or drop it if "explains why it matters" shouldn't count as a separately-assessed objective.
