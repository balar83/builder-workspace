# Stage 4 — Learning Objectives: Linear Equations

Derived from Stage 3 concepts, phrased in the same style as the existing seeded Topic (`topics.json`'s `topic-rational-numbers-basics`) — action-verb, one measurable skill per line. Grouped by section for traceability; the canonical `Topic.learningObjectives` field is a flat list, so these would be flattened at export.

## Section 1 — What is a linear equation?
1. Distinguish an algebraic expression from an equation by the presence of an equality sign.
2. Identify whether a given one-variable expression is linear (highest power = 1).
3. Identify the LHS and RHS of a given equation.
4. Verify whether a given value of the variable is a solution of a given linear equation.

## Section 2 — Solving when the variable is on both sides
5. Solve a linear equation that has the variable on both sides using transposition.
6. Solve a linear equation with a fractional coefficient by first clearing the denominator.

## Section 3 — Reducing equations to simpler form
7. Reduce a linear equation containing brackets and/or multiple denominators to a simpler linear form before solving.
8. Solve the simplified equation and check the result by substituting back into the original LHS and RHS.
