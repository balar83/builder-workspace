## AI Coaching Flow

Current implementation is linear:

Question → Hint 1 → Hint 2 → Hint 3 → Solution

Desired learning experience:

- Student attempts an answer first.
- System evaluates the answer.
- If incorrect, the learner may request Hint 1.
- Learner can try again after every hint.
- Solution is the final option, not the default path.
- AI should coach the learner rather than immediately provide answers.

Status:
Idea for future implementation after backend and answer evaluation are available.
